# Optional Cloud Extension Guide

The core curriculum is local-first. Use these extensions only when the student
has authorized accounts and the instructor has reviewed current eligibility,
permissions, budgets, and cleanup. Cloud offers change over time.

## Databricks Free Edition

Recommended first managed-platform extension:

1. Import notebooks 02 and 03.
2. Upload the Bronze API pages generated by notebook 01.
3. Replace local paths with workspace volumes or managed tables.
4. Write Silver tables as Delta.
5. Implement the CDC `MERGE` and inspect table history.
6. Capture the query plan and job metrics used in the performance discussion.

Official guide: https://docs.databricks.com/aws/en/getting-started/free-edition

## BigQuery sandbox

Recommended first real warehouse extension:

1. Create a sandbox project without a billing account.
2. Load a small Gold extract or use a public dataset.
3. Create a date-partitioned, customer-clustered table using
   `sql/bigquery_reference.sql`.
4. Compare estimated bytes with and without the partition predicate.
5. Save query text and screenshots as evidence.

Official guide: https://docs.cloud.google.com/bigquery/docs/sandbox

## AWS S3, Lambda, Glue/Athena, and CDK

1. Review current AWS Free Plan service access and set cost alerts if the account
   permits billing.
2. Create one private learning bucket with public access blocked.
3. Enable the optional S3 cell in notebook 01; use the normal AWS credential
   chain, never notebook literals.
4. From `infra/`, install its requirements and run `cdk synth` first.
5. Review the CloudFormation template, S3 notification, Lambda permission, Glue
   database, removal policies, and IAM boundary.
6. Only with explicit approval, run `cdk deploy`, upload one page, inspect the
   structured Lambda log, and then run `cdk destroy`.
7. As a separate optional lab, point an Athena table at partitioned Silver
   Parquet and compare data scanned with/without a partition predicate.
8. Glue can run the Spark transformation concepts from notebook 02, but Glue
   job configuration, roles, bookmarks, catalog permissions, and CloudWatch
   logs must be practiced before claiming Glue operations experience.

AWS Free Tier: https://aws.amazon.com/free/

## Redshift/Snowflake warehouse exercise

These products serve the same warehouse category but have different SQL, loading,
security, and operational details. This is not part of the required curriculum.
If an account is eligible for a time-limited trial:

1. Set a low maximum capacity and review usage controls.
2. For the AWS option, create the reference schema from `sql/redshift_reference.sql`.
3. Load a small Parquet dataset with the platform's `COPY` or staged-file workflow.
4. Compare plans using the platform's sort, distribution, clustering, or pruning behavior.
5. Record usage, delete the workgroup/namespace and dependent storage, and
   verify billing state immediately after the lesson.

Redshift/Snowflake trial options: https://aws.amazon.com/redshift/free-trial/ and
https://signup.snowflake.com/

## EMR boundary

Local Spark and Databricks teach Spark transformations and execution plans, but
they do not teach EMR cluster operations. An EMR extension would need to include
IAM, networking, release labels, bootstrap actions, instance/serverless sizing,
logs, retries, and teardown. Do not make EMR a required junior lab when cost or
account access is uncertain. Label it as architecture discussion unless an
actual job is submitted and observed.
