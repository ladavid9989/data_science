# Data Science Learning Repo

This branch is focused on **Git and GitHub tutoring for beginners**.

Start here:

- [Git Tutoring Home](git-tutoring/README.md)
- [Command Cheatsheet](git-tutoring/cheatsheets/git-command-cheatsheet.md)
- [Toy Streamlit Exercise](git-tutoring/exercises/toy-streamlit-app/README.md)
- [GitHub Pages Model Performance Dashboard](git-tutoring/pages/model-performance-dashboard/README.md)

The goal is to help learners understand what Git is, why GitHub matters, how local work connects to remote repositories, and how Git is used in four practical contexts:

1. Local development with JupyterLab Terminal
2. AI-assisted development with Codex
3. Web app deployment with Streamlit Community Cloud or similar hosting services
4. Static interactive dashboards with GitHub Pages, JavaScript, and Plotly
